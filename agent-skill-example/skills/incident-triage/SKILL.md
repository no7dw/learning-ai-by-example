# Incident triage procedure

1. Restate the observed symptom and the time window.
2. Separate confirmed facts from hypotheses.
3. Rank the three most likely causes using the evidence supplied by the user.
4. Ask for the smallest next diagnostic step that can distinguish the top causes.
5. Recommend mitigation before deep investigation if customer impact is active.
6. Do not invent logs, metrics, deployments, or root causes.

Return these sections:

- Impact
- Confirmed facts
- Hypotheses
- Next diagnostic step
- Mitigation
